机器凭证(cluster CA)
机器身份 = mTLS（自签 CA + per-node client cert)。独立类、永不打印、与人的 web-token 完全分离。
逐出/轮转:ccteam cluster rm <node> / ccteam cluster rotate <node>。本版不引入 CRL/OCSP —— 吊销 = rm + cert 过期 + 轮转。

新建会话

默认让调度器 自动派活(常见路径不打扰);高级可声明能力 require-tags、spec-class 或显式 pin 一台机器。
调度器将 filter 满足 {require tags} ∩ {vendor available 且 login_ok 且 version-ok} ∩ {repo 在该 node} ∩ {未触 cost-cap、未满 max_parallel} 的 node,在幸存者里按 headroom_score(算力 + 负载 + 预算加权)取最大 → 预计落 n-gpu-2(headroom 最高)。建完显示实际落点。
✕

邀请机器入队

operator 显式入网(无 mDNS/广播自动发现 — LAN footgun)。一次性短 TTL bootstrap token → Worker 本地生成 keypair + TOFU pin CA 指纹 + CSR → Control 签 client cert(CN=node_id)。
在新机上执行 ↓ (token 90s 内有效):
ccteam start --role worker \
  --control https://192.168.1.20:7332 \
  --enroll  CT-8fa31c… \
  --tags deploy,stress,e2e --class high
⚠ 单一信任域:enroll 一台 Worker = 「我信任它如同我的 Control 机」。本版不声称 per-agent / 多租户隔离;星型(Worker 间不通信)已把横向爆炸半径压到比 mesh 小。
原型说明(v0.9.0 多机协同):在 v0.8.9 统一 chat shell 上加 node 维度。左侧 项目→会话:每个 session 带 @机器徽标 标明它跑在哪台(执行钉死 owning node)、项目头标 @所属机、排队 session 显 排队#N。底部全局页新增 Machines(node card:status/spec-class/capability chips/headroom/tags/budget,含 Control 单例 + Worker + down 节点)+ 全机群会话(可按机器过滤/分组的聚合表,排队行可见);沿用 插件市场 / Status(扩成 fleet tree)/ Settings。＋ 新建会话 弹 PlacementPicker(默认 auto,高级 require-tags/class/pin)。＋ 邀请机器 弹 cluster invite(一次性 token + mTLS enroll)。点左侧会话、底部导航、顶部 Chat|终端 tab、两个弹窗均可点切演示。深色 + amber 一套 token,纯单文件、零外部 CDN。
