loop 入门启动原型 · 挑一个 loop-skill → 设 repo/预算/门 → 云端起跑 · 可点选卡片 + 起跑

这屏在说什么:ccteam = on-ramp(简便入门),不硬编码 loop

  • never hardcode a loop:每个 loop 是用户写的 SKILL.md(声明式 plan→act→verify→reflect),住 ccteam-hub,装来即用、可 fork。ccteam 的 Rust 里没有固定 loop 状态机 —— 它只提供外壳。开发者爱写啥 loop 写啥。
  • on-ramp:把门槛从 Boris 那「写一堆 bash」降到「库里挑一个 → 设 repo/预算/门 → 云端起跑」。起步库 = 那「七条可抄循环」+ elorm + oracle-first 模板,经插件市场分发。
  • stable-running = 差异化:绿框里那 5 条是 Claude Code / Codex 给不了的(云端常驻、硬预算、门到手机、可恢复、跨 vendor)。这是 ccteam 在「loop 的稳定运行」上的独有价值。
  • loop 有版本:reflect 步里 loop 想改自己(改 skill)= 跟改预言机/CLAUDE.md 同级 → 升人工门。人之后只管 curating loop 的 v1/v2。
  • 起跑后 → 进「Loops 运维台」(见 loop-ops-console.html)看预言机状态 + 成本 + 等哪道门。on-ramp 是入口,运维台是日常。
